# Građanska forenzička analiza medijske manipulacije

**Language:** Serbian  
**Status:** Published methodology  
**Portal:** https://gradjanskaforenzika.org

This methodology analyses a specific article, interview, television report, institutional statement reproduced by the media or social-media post. It separates source claims, author wording, editorial amplification, clickbait, omitted context, numerical manipulation and political steering.

Published source files:

- AI prompt: `gradjanska_forenzicka_analiza_medijske_manipulacije_v20260719-1.0`
- User guide: `gradjanska_forenzicka_analiza_medijske_manipulacije_uputstvo_v20260719-1.0`

The methodology evaluates the specific item rather than the media outlet as a whole and requires clear separation between missing evidence, unconfirmed claims and proven inaccuracy.
