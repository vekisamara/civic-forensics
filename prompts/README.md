# Civic Forensics AI Prompt Framework

This directory contains the bilingual, version-controlled prompt framework described in CFP-001 Version 0.5.

## Local civic suite — Serbian

- `local/institutional-pr-analysis/`
- `local/media-manipulation-analysis/`
- `local/political-statement-analysis/`
- `local/quick-news-analysis/`
- `local/statement-chain-analysis/`

## EU suite — English

- `eu/institutional-pr-analysis/`
- `eu/media-manipulation-analysis/`
- `eu/political-statement-analysis/`
- `eu/quick-news-analysis/`
- `eu/public-statement-analysis/`

Each methodology folder contains the published AI prompt and its corresponding user guide in a single Markdown source file.

## Shared principles

- evidence-based analysis;
- reproducibility;
- transparent source use;
- distinction between official information and independent confirmation;
- separation of fact, interpretation, inference and allegation;
- human responsibility for final conclusions;
- data minimisation and privacy protection;
- openness to correction when new evidence becomes available.
