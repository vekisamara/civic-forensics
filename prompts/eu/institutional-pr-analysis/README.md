# Institutional PR Communication Analysis — EU Edition

**Language:** English  
**Status:** Published methodology  
**Licence:** CC BY 4.0  
**Portal:** https://civicforensics.org

This methodology analyses press releases, press conferences, reports, official social-media posts and crisis communication by EU, national, regional and local authorities, public undertakings, public institutions and beneficiaries managing public or EU funds.

It distinguishes information, institutional promotion, office-holder promotion, crisis PR, formal transparency, reputational redirection, institutional minimisation and evidence-related concealment risk. It also separates EU allocation from contracting, payment, absorption, outputs and demonstrated impact.
