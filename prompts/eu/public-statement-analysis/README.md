# Public Statement Analysis Protocol — EU Edition

**Language:** English  
**Status:** Published methodology  
**Licence:** CC BY 4.0  
**Portal:** https://civicforensics.org

This comprehensive protocol examines statements by public officials, public authorities, EU institutions, political representatives, publicly funded organisations and regulated entities exercising public responsibility.

It assigns stable claim IDs, records evidence type and confidence, separates official data from independent confirmation, tracks promises and deadlines, checks numerical methodology and distinguishes EU, national, regional and local competences. Findings remain open to correction when new evidence becomes available.
