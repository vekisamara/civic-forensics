# Civic Forensics — EU English Edition

This folder contains English-language Civic Forensics prompts adapted for use in EU Member States and for matters involving EU institutions, EU law, EU funding and multi-level governance.

Author: **Velimir Samara**

### Quick citizen analysis

- [`quick-news-analysis/README.md`](quick-news-analysis/README.md) — combined, publication-ready prompt and user guide.
- [`quick-news-analysis/quick-citizen-analysis-prompt.txt`](quick-news-analysis/quick-citizen-analysis-prompt.txt) — canonical plain-text prompt.
- [`quick-news-analysis/short-user-guide.txt`](quick-news-analysis/short-user-guide.txt) — concise practical instructions.

### Full public statement analysis protocol

- [`public-statement-analysis/README.md`](public-statement-analysis/README.md) — overview and publication metadata.
- [`public-statement-analysis/user-guide.txt`](public-statement-analysis/user-guide.txt) — detailed user guide.
- `public-statement-analysis/protocol/part-01.txt` through `part-05.txt` — the continuous full protocol.

The five protocol parts form one continuous prompt and should be copied in numerical order into the AI tool.
