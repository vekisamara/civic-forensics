# Media Manipulation Analysis — EU Edition

**Language:** English  
**Status:** Published methodology  
**Licence:** CC BY 4.0  
**Portal:** https://civicforensics.org

This methodology analyses a specific media item and separates the contribution of the original source, article author, editorial framing and platform distribution. It checks unsupported claims, selective presentation, emotional framing, misleading headlines, clickbait, numerical manipulation, visual framing and political steering.

The EU edition also tests whether EU institutions, Member State authorities and different legal instruments are described accurately, and whether translation or cross-border republication changes meaning.
