# CFP Template Catalogue

| ID | Document type | Primary use | Typical length |
|---|---|---|---|
| CFP-001 | Executive Portfolio | Universal institutional presentation | 25–40 pages |
| CFP-002 | Programme Portfolio | Detailed programme and donor presentation | 15–30 pages |
| CFP-003 | Capability Statement | Rapid presentation of capacity and assets | 2–4 pages |
| CFP-004 | Executive Brief | First-contact attachment or meeting handout | 1 page |
| CFP-005 | Partner Pack | Tailored cooperation package | 5–12 pages |
| CFP-006 | Media Kit | Public identity, descriptions and assets | variable |
| CFP-007 | Annual Report | Yearly results, governance and learning | 20–40 pages |
| CFP-008 | Strategic Roadmap | Priorities, milestones and dependencies | 8–15 pages |
| CFP-009 | Investment Memorandum | Funding case and implementation model | 10–20 pages |
| CFP-010 | Presentation Deck | Meetings, briefings and public presentations | 12–20 slides |

## Common metadata

Every template must include document ID, publication version, template version, date, status, publisher, intended audience, stable URL, repository path and version history.

## Relationship rule

A CFP document may refer to ECW publications as evidence of capacity, but CFP and ECW retain separate identifiers, version histories and visual accents.
