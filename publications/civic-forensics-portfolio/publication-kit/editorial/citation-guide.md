# CFP Citation Guide v1.0

## Recommended citation

Civic Forensics, *[Title]*, Civic Forensics Portfolio, [Document ID], Version [X.X], [Month Year].

Example:

Civic Forensics, *Civic Forensics Executive Portfolio 2026*, Civic Forensics Portfolio, CFP-001, Version 1.0, 2026.

## Source hierarchy

1. Primary legal and institutional sources.
2. Civic Forensics published outputs and repository records.
3. Official programme or partner documents.
4. Reputable research and policy literature.
5. Media sources only where they document public statements or developments not available from a primary source.

## Links

Use stable URLs where possible. For repository material, cite the file path and commit or release when the document is intended to remain fixed.

## Evidence labels

Portfolio claims may use these labels:

- **Published output** — publicly available and versioned.
- **Operational asset** — currently usable platform, method or tool.
- **Prototype** — functional but not production-ready.
- **Concept** — documented design not yet implemented.
- **Planned** — intended future output subject to resources.

## Partner references

Do not describe an organisation as a partner, supporter or endorser without documented consent. Use “potential cooperation area” for prospective relationships.
