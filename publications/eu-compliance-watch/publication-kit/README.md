# ECW Publication Kit v3.0

Standardised publication system for the **EU Compliance Watch** series of Civic Forensics.

## Series

- `ECW-DD-xxx` — Deep Dive
- `ECW-WR-xxx` — Watch Report
- `ECW-CG-xxx` — Citizen Guide
- `ECW-CL-xxx` — Citizen Checklist

## Package contents

- `visual-identity/` — visual identity, colour palette and series mark
- `editorial/` — editorial and citation standards
- `templates/` — structures for four publication types
- `styles/` — digital styles for the portal and HTML export
- `metadata/` — machine-readable publication schema
- `image-prompts/` — standardised prompts for featured illustrations

## Core principle

Every publication must allow the reader to distinguish:

1. a verified fact;
2. a legal or regulatory rule;
3. an analytical conclusion;
4. an open question;
5. a recommended action;
6. missing evidence.

## Publication workflow

`Research dossier → Civic Forensics analysis → Publication → Companion package → Version update`

## Minimum metadata

Each publication contains the series, document number, title, version, date, status, language, publisher, recommended citation, category, keywords and version history.
