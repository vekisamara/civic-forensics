# Global Analyses

This directory contains selected English-language analyses from outside the primary EU focus.

A global case should be included only when it has clear comparative, educational or methodological value. It should illustrate a recurring pattern that can inform analysis of public administration and institutional accountability elsewhere.

## Priority themes

- public administration and good governance;
- access to information and public records;
- public spending, procurement and public assets;
- digital rights and data governance;
- AI governance and automated public decisions;
- institutional accountability and enforcement;
- quantitative claims, indicators and performance reporting;
- civic participation, oversight and democratic resilience.

## Selection criteria

A case should normally satisfy all of the following:

1. reliable primary or independently verifiable sources are available;
2. the public-interest relevance extends beyond a local news event;
3. the case can be analysed through a defined Civic Forensics question;
4. the analysis explains jurisdictional differences and does not project EU law onto another legal system;
5. the case offers a useful comparison, warning, method test or transferable lesson.

## Suggested classification


## Comparative note

Where an analysis compares a global case with EU standards, clearly separate:

- the law and institutional rules that actually apply to the case;
- non-binding international or regional standards;
- the EU comparison used for analytical purposes;
- the author’s inference or recommendation.

Use the templates in [`../_templates/`](../_templates/README.md) when opening a new analysis.
