# Analysis Assets

This directory is reserved for reusable, public and properly redacted visual material supporting published analyses.

Recommended subdirectories should be created only when needed:

```text
images/
charts/
evidence/
```

Case-specific files should normally remain inside the relevant analysis folder rather than in this shared directory.

## Publication rules

- Upload only material that may lawfully be made public.
- Remove unnecessary personal data, signatures, contact details, identifiers and hidden metadata.
- Preserve a clear distinction between the original source and the public redacted copy.
- Use descriptive English filenames with lowercase letters and hyphens.
- Record the source, date, rights holder and any modification or redaction.
- Do not upload private evidence merely to make repository links complete.
- Charts must identify their source data, coverage, units and methodology.
- Screenshots must preserve enough context to avoid misleading presentation.

## Suggested naming

```text
2026-07-eu-report-figure-01.png
2026-07-source-document-redacted.pdf
2026-07-indicator-comparison.csv
```
